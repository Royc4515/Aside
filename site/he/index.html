Aside בפעולה

Alt + A פותח את הסיידבר, סיכום של העמוד זורם תוך שניות, ומעבר בין ספקים הוא לחיצה אחת.

מה זה Aside?

Aside הוא תוסף Chrome חינמי בקוד פתוח שפותח סיידבר AI בכל אתר. הוא קורא את העמוד שאתם נמצאים בו, כך שאפשר לסכם, לתרגם, לחלץ נתונים או לשוחח עליו עם Claude, OpenAI GPT, Gemini, Grok, Groq או מודל Ollama מקומי, בלי להעתיק ולהדביק ובלי לעזוב את הטאב. הוא עובד בשיטת BYOK (Bring Your Own Key): אתם מוסיפים מפתח API משלכם, המפתח נשאר בדפדפן, וכל בקשה נשלחת ישירות לספק שבחרתם. הממשק זמין באנגלית ובעברית, עם תמיכה מלאה בכיווניות מימין לשמאל (RTL).

השוואה זה לצד זה

הצמידו שני ספקים זה לצד זה ושלחו את אותו פרומפט לשניהם. התשובות זורמות במקביל.

המפתחות שלכם, נשארים אצלכם

השתמשו במפתחות ה-API שכבר יש לכם. אנחנו לא רואים, לא שומרים, ולא מעבירים אותם דרך שום שרת.

היסטוריה מקומית

כל שיחה נשמרת באחסון המקומי של הדפדפן. ללא חשבון, ללא ענן, ללא איסוף נתונים.

תבניות פרומפט

פרומפטים מוכנים בלחיצה אחת למשימות היומיומיות: נקודות עיקריות, משימות לביצוע, הסבר פשוט, טיעוני נגד, בלי ז׳רגון ותרגום לעברית.

עובד בכל טאב

לחצו Alt+A בכל עמוד. הסיידבר נפתח עם ההקשר של מה שאתם קוראים, ולא מפריע.

תשובות בשמונה שפות

הממשק באנגלית או עברית (תמיכה מלאה ב-RTL); אפשר לבקש מהמודל לענות באחת משמונה - אנגלית, עברית, ספרדית, צרפתית, גרמנית, סינית, ערבית או יפנית.

הדרך הקלה להשתמש ב-AI

מראה מוכר, בלי עומס ויזואלי. בנוי לחיות לצד התוכן, לא להחליף אותו.

מותקן ומוכן בשתי דקות

שני שלבים קצרים. הראשון מתקין את התוסף, השני מביא לכם מפתח API חינמי כדי שתוכלו להשתמש בו באמת.

שלב 1

התקנת Aside ב-Chrome

בלי build, בלי npm. פשוט להוריד ולטעון את התיקייה. כ-30 שניות.

  1. 1
    הורידו את Aside

    קחו את קובץ aside.zip הרזה (כ-83 KB) וחלצו אותו לכל מקום במחשב.

    הורדת ZIP →
  2. 2
    פתחו את דף התוספים של Chrome

    הדביקו chrome://extensions בשורת הכתובת ולחצו Enter.

  3. 3
    הפעילו מצב מפתחים

    מתג בפינה הימנית למעלה. בלעדיו Chrome לא יטען תוסף לא ארוז.

  4. 4
    טענו תוסף לא ארוז

    לחצו Load unpacked ובחרו את תיקיית aside שחילצתם (זו שמכילה את manifest.json).

  5. 5
    הצמידו לסרגל הכלים

    לחצו על אייקון הפאזל בסרגל והצמידו את Aside, כדי שיהיה במרחק לחיצה.

  6. 6
    הגדירו את קיצור Alt + A

    Chrome מגדיר קיצורים אוטומטית רק לתוספים מה-Web Store, אז הגדירו אותו פעם אחת ידנית: פתחו chrome://extensions/shortcuts, מצאו את Aside, לחצו על התיבה ליד “Toggle the AI sidebar” ולחצו Alt + A. מעכשיו הוא נפתח בכל עמוד.

שלב 2 · חינם

מפתח API חינמי של Groq

Groq מריצים את GPT-OSS 120B של OpenAI במהירות שיחה אמיתית, עם tier חינמי - מושלם לשימוש יומיומי. כ-60 שניות.

  1. 1
    פתחו את הקונסולה של Groq

    דף sign-in פשוט - Google, GitHub או מייל, כולם עובדים.

    פתיחת console.groq.com/keys →
  2. 2
    התחברו

    ללא כרטיס אשראי. ה-tier החינמי מכסה עשרות אלפי בקשות ביום.

  3. 3
    צרו מפתח API

    לחצו Create API Key, תנו לו שם (למשל Aside), ואשרו.

  4. 4
    העתיקו את המפתח

    Groq מציגים את המפתח פעם אחת בלבד. העתיקו עכשיו - תמיד אפשר ליצור עוד אחד אחר כך.

  5. 5
    הדביקו ב-Aside

    פתחו את Aside ← הגדרות ← Groq, הדביקו את המפתח, ושמרו. הסיידבר בודק את המפתח מול ה-API לפני שמירה.

המפתחות שלכם נשארים בדפדפן

Aside פועל 100% בצד הלקוח. מפתחות API נשמרים ב-chrome.storage.local - על המכשיר שלכם בלבד, ללא סנכרון וללא העלאה לשום מקום. הבקשות נשלחות ישירות מהדפדפן אל הספק שבחרתם. ללא טלמטריה, ללא איסוף נתונים, ללא שרת באמצע.

קראו את מדיניות הפרטיות המלאה

שאלות נפוצות

האם Aside חינמי?

התוסף עצמו חינמי וקוד פתוח. על השימוש משלמים ישירות לספק ה-AI שבחרתם - או שמשתמשים במסלול החינמי שלו. ל-Groq ול-Gemini יש מסלול חינמי.

איפה מפתחות ה-API שלי נשמרים?

ב-chrome.storage.local - על המכשיר שלכם בלבד. הם לא מסונכרנים, לא מועלים ולא נשלחים לאף שרת (פשוט כי אין לנו שרת). גם היסטוריית השיחות נשמרת מקומית בלבד.

זה עובד עם המנוי שלי ל-ChatGPT Plus או ל-Claude Pro?

לא. Aside עובד בשיטת BYOK: הוא פונה ל-API של כל ספק עם מפתח API שאתם יוצרים בקונסולה של אותו ספק, והשימוש ב-API מחויב בנפרד ממנויי הצ׳אט. ל-Groq ול-Gemini יש מסלול API חינמי, ומודל Ollama מקומי לא צריך מפתח בכלל.

אפשר לבחור איזה מודל כל ספק משתמש בו?

כן. לכל ספק יש מודל ברירת מחדל, ואפשר להחליף מודל ישירות מתיבת ההקלדה (או בהגדרות ← מודל), למשל Claude Sonnet 5.5, Opus 5.5 או Haiku 5.5. יש גם שדה Custom להקליד כל מזהה מודל שהספק תומך בו, כך שלעולם לא תהיו תקועים בהמתנה שנוסיף מודל חדש. מזהים מותאמים נשמרים לכל ספק ומופיעים מחדש תחת "Saved custom" לשימוש חוזר בלחיצה אחת.

אילו ספקים נתמכים?

Anthropic Claude, OpenAI ChatGPT, Google Gemini, xAI Grok, Groq, ו-Ollama להרצה מקומית. קל להוסיף עוד - הקוד פתוח ב-GitHub.

אילו שפות נתמכות?

הממשק מגיע באנגלית ובעברית עם תמיכה מלאה ב-RTL, והסיידבר מתיישר לכיוון של אתרים מימין לשמאל כמו אתרים בעברית או בערבית. המודל יכול לענות באחת משמונה שפות: אנגלית, עברית, ספרדית, צרפתית, גרמנית, סינית, ערבית ויפנית. במצב Auto הוא עונה בשפת העמוד.

Aside נמצא ב-Chrome Web Store? איך מתקינים?

עדיין לא. מורידים את aside.zip מה-release האחרון ב-GitHub, מחלצים, פותחים chrome://extensions, מפעילים מצב מפתחים ולוחצים Load unpacked. לוקח כ-30 שניות, בלי build ובלי חשבון.

מה Aside שולח, ולמי?

רק מה שביקשתם. כששולחים פרומפט, Aside מצרף לבקשה הזו את הטקסט הקריא של העמוד (עד 12,000 תווים) ושולח אותה ישירות מהדפדפן לספק שבחרתם. אפשר לכבות את הקשר העמוד בלחיצה אחת. שום דבר לא מועלה ברקע, ואין איסוף נתונים או טלמטריה.

האם זה יעבוד ב-Firefox או ב-Edge?

Edge כן (מבוסס Chromium). Firefox עדיין לא נארז - מוזמנים לעזור עם זה ב-GitHub.
