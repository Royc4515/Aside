The easy way to use AI

Familiar look, no glaring chrome — built to live next to whatever you're reading.

Up and running in two minutes

Two short setups. The first installs the extension; the second gets you a free API key so you can actually use it.

Step 1

Install Aside on Chrome

No build step, no npm. Just download and load the folder. About 30 seconds.

  1. 1
    Download Aside

    Grab the slim aside.zip (~83 KB) and unzip it anywhere on your machine.

    Download ZIP →
  2. 2
    Open Chrome extensions

    Paste chrome://extensions into the address bar and press Enter.

  3. 3
    Turn on Developer mode

    Top-right toggle. Without it, Chrome won't load an unpacked extension.

  4. 4
    Load unpacked

    Click Load unpacked and select the unzipped aside folder (the one containing manifest.json).

  5. 5
    Pin it to the toolbar

    Click the puzzle icon in the toolbar and pin Aside so it's one click away.

  6. 6
    Set the Alt + A shortcut

    Chrome only auto-assigns shortcuts for Web Store extensions, so set it once by hand: open chrome://extensions/shortcuts, find Aside, click the box next to Toggle the AI sidebar, and press Alt + A. Now it opens on any page.

Step 2 · Free

Get a free Groq API key

Groq runs OpenAI's open-weight GPT-OSS 120B at conversational speed and has a free tier — perfect for daily use. About 60 seconds.

  1. 1
    Open the Groq console

    A clean sign-in page — Google, GitHub, or email all work.

    Open console.groq.com/keys →
  2. 2
    Sign in

    No credit card required. The free tier covers tens of thousands of requests per day.

  3. 3
    Create an API key

    Click Create API Key, name it something like Aside, and confirm.

  4. 4
    Copy the key

    Groq shows the key once. Copy it now — you can always create another later.

  5. 5
    Paste it into Aside

    Open Aside → Settings → Groq, paste the key, save. The sidebar validates it live before storing.

Your keys stay in your browser

Aside is 100% client-side. API keys live in chrome.storage.local — on your device only, never synced or uploaded anywhere. Requests go directly from your browser to the provider you chose. No telemetry, no analytics, no server in the middle.

Frequently asked

Is Aside free?

The extension is free and open source. You pay each AI provider directly for usage (or use a free tier — Groq and Gemini both offer one).

Where are my API keys stored?

In chrome.storage.local — on your device only. They are never synced, uploaded, or sent to any server (there is no server we control). Conversation history is stored locally only, too.

Can I choose which model each provider uses?

Yes. Each provider ships with a sensible default, and you can switch model right from the composer (or in Settings → Model), e.g. Claude Sonnet 5.5, Opus 5.5, or Haiku 5.5. There's also a Custom field to type any model id the provider supports, so you're never stuck waiting for us to add a new one. Custom ids are saved per provider, so they reappear under Saved custom for one-click reuse.

Which providers are supported?

Anthropic Claude, OpenAI ChatGPT, Google Gemini, xAI Grok, Groq, and self-hosted Ollama. Adding more is straightforward — see the repo.

Which languages does it support?

The interface ships in English and Hebrew (full RTL). You can ask the model to reply in any of eight languages: English, Hebrew, Spanish, French, German, Chinese, Arabic, and Japanese.

Can I run it on Firefox or Edge?

Edge yes (Chromium-based). Firefox isn't packaged yet — contributions welcome.
